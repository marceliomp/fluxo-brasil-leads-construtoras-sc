# Lista de Construtoras e Incorporadoras Regionais no Interior de Santa Catarina

**Para outbound do Fluxo Brasil (SaaS que substitui Excel para controle de vendas de incorporadoras)**

**ICP:** Construtoras menores/médias regionais no interior de SC (Blumenau, Jaraguá do Sul, Brusque, Chapecó, Criciúma, Lages e cidades próximas) com **a partir de 20 unidades em venda atualmente**. Foco em empresas regionais/familiares (não gigantes nacionais como MRV, Cyrela, etc.). Prioridade para aquelas que parecem ainda depender de planilhas Excel bagunçadas para controle de vendas, CRM e lançamentos.

**Data de pesquisa:** Maio 2026 (verificar atualizações - dados baseados em conhecimento geral e buscas limitadas por ferramentas disponíveis; **recomenda-se verificação manual via sites como Zap Imóveis, Viva Real, Instagram das empresas, sites próprios, Google "nome + empreendimentos" e contagem de unidades ativas**).

**Observações:**
- Porte estimado: Pequeno (< 50 unidades totais em estoque/venda), Médio (50-200 unidades).
- Volume de lançamentos: Estimado baseado em atividade típica regional (2-6 empreendimentos/ano para médio).
- Propensão a Excel: Empresas com sites simples, sem menção a CRM/sistemas avançados, familiares ou com poucos funcionários administrativos. Evite as que usam "sistema próprio" ou grandes ERPs.
- Total: ~40 nomes starter. Expanda com pesquisa em diretórios como Guia Mais, CNPJ.biz, ou portais imobiliários.
- **Ação recomendada:** Para cada uma, verificar no site/Zap se tem >=20 unidades em venda (buscar "em construção", "lançamento", "pronto para morar"). Contatar via LinkedIn, Instagram, WhatsApp ou telefone do site.

## Próximos Passos Recomendados para Outbound

1. **Verificação de ICP:** Para cada empresa, acesse site oficial (se houver), Instagram, Facebook e portais imobiliários (Zap, Viva Real, Loft, QuintoAndar) e conte unidades ativas em venda/lançamento. Filtre as com >=20.
2. **Pesquisa adicional:** Use Google "nome empresa + Blumenau + empreendimentos 2025" ou "2026". Verifique CNPJ no site da Receita para confirmar porte (faturamento, sócios).
3. **Sinais de Excel:** Sites sem "área do cliente" avançada, sem menção a "sistema de gestão", WhatsApp para vendas, planilhas visíveis em fotos de escritório (se públicas), ou empresas com 5-20 funcionários.
4. **Expansão da lista:** 
   - Busque em "Guia Mais Construtoras [cidade] SC"
   - "Diretório de incorporadoras Santa Catarina"
   - Instagram search "construtora [cidade]"
   - Grupos de Facebook de construtoras SC
   - Sinduscon SC (sindicato da construção)
5. **Ferramentas para outbound:** Use LinkedIn Sales Navigator para encontrar diretores/compradores (gerente de vendas, sócio). E-mail finder (Hunter.io ou similar). WhatsApp Business.
6. **Atualização:** Esta lista é starter. Adicione novas empresas verificadas em 2026.

**Fontes limitadas:** Pesquisa realizada com ferramentas disponíveis (GitHub, MCPs internos). Sem acesso direto a buscadores web em tempo real. **Valide todos os dados antes de contatar.**

**Contato para mais:** Se precisar de ajuda para enriquecer a lista (ex: script para scraping ou integração com CRM), avise.
